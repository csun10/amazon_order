# Excel转JSON转换器GUI使用指南

## 功能概述

增强版Excel转JSON模板转换器提供了用户友好的图形界面，支持两种转换模式：

### 🔧 手动模式
- 选择特定的Excel文件转换为特定的JSON模板
- 完全控制文件配对关系
- 适合处理单个或少量文件

### ⚡ 批量模式  
- 自动处理PO_excel文件夹中的所有Excel文件
- 自动匹配对应的JSON模板文件
- 适合批量更新大量模板

## 启动方式

### 方式1：双击批处理文件
```
启动Excel转JSON转换器.bat
```

### 方式2：命令行启动
```bash
cd order_generation
python excel_to_json_gui.py
```

## 界面说明

### 转换模式选择
- **手动模式**：精确控制每个文件的转换配对
- **批量模式**：自动匹配PO_excel中的文件

### 手动模式操作

#### 添加文件配对
1. 点击 **"添加文件配对"** 按钮
2. 在文件选择对话框中选择Excel文件
3. 输入目标JSON模板名称（不含.json扩展名）
4. 确认添加到配对列表

#### 管理配对列表
- **移除选中配对**：删除选中的文件配对
- **清空全部**：清除所有配对关系
- **转换配对文件**：开始转换所有配对的文件

#### 配对列表显示
| Excel文件 | JSON模板名 |
|-----------|------------|
| example.xlsx | example.json |

### 批量模式操作

#### 文件匹配预览
系统自动扫描并显示文件匹配状态：

| Excel文件 | JSON模板 | 状态 |
|-----------|----------|------|
| product1.xlsx | product1.json | ✓ 已匹配 |
| product2.xlsx | 无对应JSON | ✗ 未匹配 |

#### 状态说明
- **✓ 已匹配**：Excel文件名与JSON模板名一致，可以转换
- **✗ 未匹配**：没有对应的JSON模板文件

#### 批量操作
- **刷新文件列表**：重新扫描文件夹并更新匹配状态
- **转换全部匹配文件**：处理所有已匹配的文件对

## 转换过程

### 进度显示
- **进度条**：显示当前转换进度
- **状态文本**：显示正在处理的文件
- **详细日志**：记录每个文件的转换结果

### 转换结果
每个文件的转换结果会显示：
- ✓ **成功**：文件转换成功并生成JSON模板
- ⚠ **警告**：部分成功或需要注意的问题
- ✗ **错误**：转换失败及错误原因

### 转换总结
转换完成后显示：
- 处理的文件数量
- 成功转换的数量
- 生成的JSON模板总数
- 输出目录位置

## 文件要求

### Excel文件格式
- 必须使用标准的Excel模板格式
- 支持.xlsx和.xls格式
- 文件需包含有效的产品数据

### 文件命名规则
- Excel文件名应与产品SKU一致
- JSON模板文件命名：`SKU.json`
- 建议使用英文和数字，避免特殊字符

### 目录结构
```
order_generation/
├── PO_excel/           # Excel源文件目录
├── json_template/      # JSON模板输出目录
├── excel_to_json_gui.py
└── 启动Excel转JSON转换器.bat
```

## 常见问题

### Q: 为什么Excel文件没有生成对应的JSON？
A: 检查以下几点：
- Excel文件格式是否正确
- 文件中是否包含有效的产品数据
- 产品SKU是否在数据行中存在

### Q: 批量模式下某些文件显示"未匹配"？
A: 这是正常的，表示：
- 该Excel文件没有对应的JSON模板文件
- 或者文件名不完全匹配
- 这些文件不会在批量转换中处理

### Q: 转换后的JSON文件在哪里？
A: 所有生成的JSON模板文件保存在：
```
order_generation/json_template/
```

### Q: 可以同时运行多个转换任务吗？
A: 不建议，GUI在转换期间会锁定界面以确保数据一致性。

## 高级功能

### 富文本支持
- 自动检测Excel中的文本格式
- 保留粗体、颜色等格式信息
- 转换为JSON富文本结构

### 错误恢复
- 单个文件失败不影响其他文件转换
- 详细错误日志帮助排查问题
- 自动跳过无效文件继续处理

### 实时反馈
- 实时显示转换进度
- 即时更新处理状态
- 背景处理保持界面响应

## 技术支持

如遇到问题，请检查：
1. Python环境是否正确安装
2. 必要的依赖包是否完整（openpyxl等）
3. 文件权限是否充足
4. Excel文件是否损坏

### 依赖要求
- Python 3.7+
- openpyxl
- tkinter（通常随Python安装）

### 故障排除
- 查看详细日志了解具体错误
- 确保文件路径中没有特殊字符
- 检查Excel文件是否被其他程序占用
