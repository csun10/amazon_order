# PO Number Update - Underscore to Dash Conversion

**Date:** February 3, 2026  
**Status:** ✓ COMPLETE  

---

## What Was Changed

### Issue
The ERP system cannot accept underscores (_) in the 采购单号 (purchase order number) field.

### Solution
Updated the code to replace all underscores with dashes (-) in:
1. Order names generated by `batch_verification.py`
2. 采购单号 field in PO import files generated by `fill_po_import.py`

---

## Files Updated

### 1. batch_verification.py
**Change:** Modified order name generation
```python
# OLD:
order_name = f"verify_{sku}"

# NEW:
order_name = f"verify-{sku}".replace("_", "-")
```

### 2. fill_po_import.py
**Change:** Modified 采购单号 field extraction
```python
# OLD:
order_number = json_file.stem

# NEW:
order_number = json_file.stem.replace("_", "-")
```
