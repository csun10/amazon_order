┌─────────────────────────────────────────────────────────────────────────────┐
│ 📁 文件夹说明 (Folder Structure)                                           │
└─────────────────────────────────────────────────────────────────────────────┘

  📝 PO_excel/         主要工作位置 - 在这里编辑Excel
  🔄 json_template/    中间格式 - Excel自动转换为JSON
  📤 PO_excel_export/  最终输出 - 用于打印/发送（只读）

  工作流程: PO_excel → json_template → PO_excel_export
  
  ⚠️ 重要: 
  - 编辑 PO_excel/ 中的文件最简单
  - 自动同步检测 PO_excel/ 中的修改
  - PO_excel_export/ 是只读输出

┌─────────────────────────────────────────────────────────────────────────────┐
│ ✅ 标准工作流程 (Standard Workflow - RECOMMENDED)                          │
└─────────────────────────────────────────────────────────────────────────────┘

  1️⃣  编辑 Excel 文件
     位置: PO_excel/*.xlsx
     提示: 使用Excel编辑最简单！
     
  2️⃣  转换为 JSON 模板
     双击: 启动Excel转JSON转换器.bat
     或运行: python excel_to_json_template.py
     自动保存到: json_template/
     
  3️⃣  生成最终 Excel 输出
     命令: python json_PO_excel.py json_template/XX.json PO_excel_export/XX.xlsx
     或简化: python json_PO_excel.py json_template/XX.json XX.xlsx
     
┌─────────────────────────────────────────────────────────────────────────────┐
│ 自动同步 (Auto Sync - Automatic JSON Update)                               │
└─────────────────────────────────────────────────────────────────────────────┘

  当你在 PO_excel/ 中编辑文件后，自动同步会更新JSON模板
  
  双击: 智能同步助手.bat (推荐)
  - 显示最近3天修改的Excel文件
  - 询问确认
  - 自动转换为JSON模板
  
  或双击: 自动同步Excel到JSON.bat (快速)
  - 直接同步最近3天的文件
  - 无需确认
  
  ⚠️ 只检测 PO_excel/ 文件夹！
  双击: 查看最近修改的文件.bat
  - 只显示文件列表
  - 不执行同步
  
  ⚠️ 注意: 只有 PO_excel/ 文件夹中的Excel会被同步！

┌─────────────────────────────────────────────────────────────────────────────┐
│ 命令行选项 (Command Line Options)                                          │
└─────────────────────────────────────────────────────────────────────────────┘

  基本用法:
  python auto_sync_excel_to_json.py
  
  自定义天数:
  python auto_sync_excel_to_json.py --days 5
  
  同步所有文件:
  python auto_sync_excel_to_json.py --check-all

┌─────────────────────────────────────────────────────────────────────────────┐
│ 重要提示 (Important Notes)                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  ✓ 默认只同步最近3天内修改的文件
  ✓ 跳过临时文件 (~$*.xlsx)
  ✓ 跳过测试文件 (test_*.xlsx)
  ✓ 同步会覆盖对应的JSON文件
  ✓ 建议使用版本控制 (Git)

  ✗ 不要在每次生成Excel后自动运行同步
  ✗ 避免循环更新
  ✗ 注意数据传输效率

┌─────────────────────────────────────────────────────────────────────────────┐
│ 故障排除 (Troubleshooting)                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

  问题: 找不到要同步的文件
  解决: 
  - 检查文件是否在 PO_excel_export/ 文件夹
  - 确认文件修改时间在3天内
  - 使用 --check-all 查看所有文件
  
  问题: 同步后JSON格式不对
  解决:
  - 确保Excel文件结构正确
  - 检查交货时间字段格式
  - 查看错误日志
  
  问题: 交货时间变成日期
  解决:
  - Excel中手动编辑时保持 "XX天" 格式
  - 不要使用Excel的日期格式
  - 或在JSON中手动调整
